# Models Directory

This directory stores trained Random Forest models and their associated metadata files generated by `train_cloud.py`.

## File Naming Convention

### Model Files (.pkl)
- Format: `rf_model_YYYYMMDD_HHMMSS.pkl`
- Example: `rf_model_20250128_143022.pkl`
- Size: ~10-50 MB (depending on n_estimators and max_depth)
- Contains: Pickled dictionary with `{'model': RandomForestRegressor, 'scaler': None}`

### Metadata Files (.json)
- Format: `rf_metadata_YYYYMMDD_HHMMSS.json`
- Example: `rf_metadata_20250128_143022.json`
- Size: ~5-20 KB
- Contains:
  - Model hyperparameters
  - Training/validation/test metrics
  - Feature names (195 features after encoding)
  - Top 20 feature importances
  - Training date and configuration

## Usage

### Training (Creates Model Files)
```bash
python train_cloud.py
```

This will create:
- `models/rf_model_YYYYMMDD_HHMMSS.pkl`
- `models/rf_metadata_YYYYMMDD_HHMMSS.json`

### Inference (Uses Model Files)
```python
from predict import CoStarPredictor

predictor = CoStarPredictor(
    model_path='./models/rf_model_20250128_143022.pkl',
    metadata_path='./models/rf_metadata_20250128_143022.json'
)

predictions = predictor.predict(data)
```

## Model Artifacts

Each training run produces two files with matching timestamps:

1. **Model file (.pkl)** - The actual trained RandomForestRegressor
2. **Metadata file (.json)** - Performance metrics and configuration

Always keep both files together for reproducibility.

## Git Ignore

Model files are typically added to `.gitignore` because:
- Large file size (~10-50 MB)
- Can be regenerated from training data
- Binary format not suitable for version control

If you need to version models, use Git LFS or cloud storage (S3, Google Drive, etc.).

## Cloud Training Workflow

1. **Train on Google Colab:**
   - Upload code and data
   - Run `train_cloud.py`
   - Download generated .pkl and .json files

2. **Local Inference:**
   - Place downloaded files in this directory
   - Use `predict.py` to make predictions locally

3. **Model Selection:**
   - Compare metadata files to choose best model
   - Use validation metrics (not test) for model selection
   - Test metrics are for final reporting only
